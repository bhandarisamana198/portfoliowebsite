# Samana’s Digital Marketing Portfolio

A personal portfolio and learning journal built with Next.js.

## Get started

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Publish a learning note

Open `content/posts.ts` and add a new item to the `posts` array. Give it a unique URL-friendly `slug`, title, date, category, reading time, a short excerpt, and an array of paragraphs in `content`. The entry appears in the journal and gets its own page at `/blog/your-slug`. Commit and deploy the update to publish it.

The sample entries are starter content and should be replaced or edited to reflect your own learning.

## Personalize before sharing

- Replace `Samana` in the site metadata and copy if you prefer another name.
- Update `hello@example.com` with your email address.
- Change the LinkedIn link in `app/page.tsx` to your profile.
- Update the location and portfolio details to match your experience.
